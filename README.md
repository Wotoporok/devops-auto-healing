# DevOps Auto-Healing Platform

Infrastructure monitoring and automatic recovery platform based on:

- Docker
- Prometheus
- Grafana
- Alertmanager
- Node Exporter
- cAdvisor
- Python
- FastAPI
- GitHub Actions
- Trivy

## Project goal

The project provides infrastructure monitoring and automatic recovery
of failed Docker services.
